# VerityPDF brand assets

`verity-mark.png` is the transparent master raster mark generated for the
VerityPDF rebrand. The mark uses a folded copper **V** with a page-corner
detail and is designed to remain recognizable at application-icon sizes.

`src-tauri/icons/app-icon.svg` is the deterministic vector companion used for
favicons and documentation. Platform icon files are generated from the raster
master with Tauri's icon generator.

The master mark was generated with OpenAI's built-in image generation tool
using the user-provided concept image only as a visual reference, followed by
local chroma-key removal.
